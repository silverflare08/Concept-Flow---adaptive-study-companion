# Sample study material

These original files contain no private student data and can be used to explore ConceptFlow.

1. Create a workspace called **Graph basics**.
2. Upload `graph-basics.md`. Optionally add `bfs_example.py` and `practice-results.csv`.
3. Ask **Why does BFS use a queue?** Open the citation and compare it with the notes.
4. Ask a question outside the material, such as **How do I calculate an eigenvalue?**, to see how unsupported queries are handled.
5. Generate a learning flow or revision map, then try a short BFS quiz.
6. Open the saved report in Progress and review your answers.
7. Add a material note or study reminder and return to it after refreshing.
8. Download a lesson or report in your preferred format.

To try handwriting, photograph a few handwritten lines from the notes. To try speech, record a short explanation and upload it.

The CSV is sample input data; uploading it does not create assessment history. AI wording and questions vary, so use the original notes to check the output.
